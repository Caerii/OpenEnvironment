# Texture Assets

This directory needs 4 tileable texture images for the terrain shader:

- **grass.jpg** - Green grass texture (512×512 or larger)
- **rock.jpg** - Rocky/stone texture (512×512 or larger)
- **sand.jpg** - Sandy desert texture (512×512 or larger)
- **snow.jpg** - White snow/ice texture (512×512 or larger)

## Where to Get Textures

You can use:
1. Free tileable textures from [Poly Haven](https://polyhaven.com/textures)
2. [CC0 Textures](https://cc0textures.com/)
3. Generate with AI (Stable Diffusion, etc.)
4. Any 512×512 JPG images (for quick testing, even solid colors work)

## Quick Test (Solid Colors)

For immediate testing, you can create solid color placeholders:
- grass.jpg → bright green (#4CAF50)
- rock.jpg → gray (#808080)
- sand.jpg → tan/beige (#D2B48C)
- snow.jpg → white (#FFFFFF)

Just ensure they're named exactly as above and placed in this directory.
